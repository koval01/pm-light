# Support

Proton Mail Light is an **unofficial** client, not affiliated with Proton AG. **Proton's support cannot help with
it**, and questions about it do not belong there.

- **A bug or a missing feature in this client:** open an [issue](https://github.com/koval01/pm-light/issues/new/choose).
  The app's journal (Settings, Journal) holds no personal data and helps to find a cause.
- **A problem with your Proton account itself** (sign-in refused, a locked account, billing): that is Proton's to
  answer, at [proton.me/support](https://proton.me/support).
- **A security problem:** never in an issue. See [the security policy](.github/SECURITY.md).
